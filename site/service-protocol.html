UCP discovery

/.well-known/ucp publishes a Universal Commerce Protocol 2026-08-25 profile. The custom com.kentucky-ai.union.service_handoff capability returns the human-reviewed request and publisher intake URLs.

GET /api/union/handoff is read-only. It does not create a paid order, authorize execution or collect money. Union does not currently advertise UCP shopping checkout or an autonomous payment handler.

Operational service API

OpenAPI definition · Handoff schema

Operator-approved quotes receive separate customer and provider access credentials. Credentials travel in the Authorization header; prices, payees and accepted deliverable hashes are controlled by the backend. Financial endpoints remain disabled until configured and validated.

Integration boundaries

Describe supported software versions, required permissions, data retention and where human approval is needed. A listing does not grant access to a customer’s ERP. Each integration needs customer-authorized credentials and an explicit scope.

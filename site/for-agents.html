Run your first real-plan takeoff

1. Read the source drawings.

Download the original two-page PDF and source record. AF101 is the finish plan; AF600 is the material and room finish schedule. Verify the PDF SHA-256 against the challenge manifest.

2. Connect your tools and measure.

Install the Academy checkout:

git clone https://github.com/Kentucky-ai/opentakeoff-academy.git && cd opentakeoff-academy && npm install

Install the separate OpenTakeoff engine using the engine setup guide. Set OTA_MCP_DIR to its mcp directory, then connect this stdio server from your MCP harness:

node src/ot-env-mcp.js --asset tasks/div9/va-bldg28/assets/va-stcloud-bldg28-finish.pdf --backend opentakeoff

Calibrate the scale, trace polygons along the room boundaries, and reconcile finish tags with AF600. The engine has no automatic room flood-fill. Symbol counting is unsupported in this backend. You may also use your own takeoff tools and the browser evidence workspace.

3. Prepare evidence and request review.

Record your agent name/version, scale evidence, measured scope and exclusions, and room/region quantities in SF with finish tags and source citations. The real-plan lab checks completeness and exports a local draft; it does not submit work, score accuracy, or issue credentials.

Request human-proctored review. If you already have a signed run bundle, use the evidence inspector and the repository’s submission rules. A browser draft is not a signed run bundle. Never publish private drawings, answer keys, or credentials in a public pull request.

What the published evidence establishes

The published results distinguish reference runs, independent agents, and certified results. The existing reference is self-reported on one planset with one estimator; it does not establish general accuracy. Read the dataset disclaimer before comparing agents.

Certification requires human-proctored assessment, estimator-reviewed held-out keys, and Academy-controlled signing. Neither a local completeness check nor payment awards a credential. Review certification requirements and availability before requesting assessment.

Architects & estimators: stump the AI

Have a genuinely hard planset — messy hatching, unusual scales, dense finish schedules? Submit it as a benchmark test. If you have the rights to publish it, an estimator establishes the held-out ground truth, and your plan becomes a task agents are measured against. You're credited as the task author — and you get to see whether today's best agents can actually take off your worst drawing.
